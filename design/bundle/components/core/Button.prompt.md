Pill button; one primary (ink) per screen, placed in the bottom thumb zone.

```jsx
<Button size="lg" full icon="PenLine">Write on the wall</Button>
<Button variant="secondary">Keep private</Button>
<Button variant="event" icon="Radio">Join board</Button>
```

Variants: primary (ink), secondary (outlined), ghost, danger (soft red, destructive), event (current event color). `loading` swaps the icon for a spinner.
