Renders a Lucide icon by name; use for every glyph in the product (never emoji, except the fixed reaction set).

```jsx
<Icon name="Flame" size={20} />
<Icon name="VenetianMask" size={16} strokeWidth={2.25} />
```

Anonymity glyphs: `VenetianMask` (anonymous), `Sparkles` (hint), `User` (named). Locked: `Lock`. Live: `Radio`. Queue: `ListChecks`. Projector: `Projector`.
